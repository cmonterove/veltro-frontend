# Veltro

Tareas (estilo Monday) + docs (estilo Notion) + reuniones de Google Calendar, conectados.

## Arrancar

```bash
npm install
npm run dev
```

Con `NEXT_PUBLIC_DEMO=1` en `.env.local` corre con datos de prueba, sin Supabase ni Google.

Arquitectura, reglas de negocio y cómo conectar Supabase y Google Calendar: [VELTRO_PROJECT.md](VELTRO_PROJECT.md).
